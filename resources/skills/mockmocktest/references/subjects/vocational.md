# 직업탐구 전 과목

2027: 성공적인 직업생활 + 선택 5과목의 구조다. 1과목 응시는 농업 기초 기술·공업 일반·상업 경제·수산·해운 산업 기초·인간 발달 중 하나, 2과목은 성공적인 직업생활과 선택 하나다. 과목당 20문항·30분·50점·2/3점.

2028: **성공적인 직업생활** 단일 출제, 25문항·40분·50점·1.5/2/2.5점. 옛 선택과목 전문 범위를 합친 시험으로 만들지 않는다. 학교 교육과정·실습 자료·공식 기출의 범위를 우선한다.

| 과목 | 자료·문항 설계 | 검증 |
|---|---|---|
| 성공적인 직업생활 | 진로 설계·직업 윤리·조직 의사소통·근로관계·산업안전 사례와 절차/계약 자료 | 역할·권리·의무·상황 조건이 명확해야 한다. 법령은 적용 시점을 확인하고 위험 행동을 정답으로 만들지 않는다. |
| 농업 기초 기술 | 재배·사육·농업 자원·기술·유통 상황, 생육 사진·작업 공정·환경 자료 | 종/생육 단계·계절·환경 요인·단위, 안전 수칙과 생산 과정의 인과 |
| 공업 일반 | 생산·설계·재료·에너지·품질·안전의 기초 문제, 장치/공정 도식 | 부품 연결·공정 순서·기호·치수, 보존 관계와 작업 안전 |
| 상업 경제 | 경제 활동·기업 경영·금융·유통·무역 사례, 거래표·지표 | 단위·잔액·원가/수익·환율 방향·거래 주체, 제도 적용 시점 |
| 수산·해운 산업 기초 | 해양 환경·수산 자원·선박/항해·물류 자료, 지도·장비 사진 | 좌표·방향·조석·속력/거리/시간·자원 관리·안전 조건 |
| 인간 발달 | 발달 단계·발달 원리·생활 환경·돌봄 사례, 관찰 기록과 변화 그래프 | 개인차를 보존하고 한 행동으로 진단하지 않는다. 발달 순서·연령 범위·자료의 한계 |

실습 맥락을 일반 상식 문제로 바꾸지 않는다. 장비 사진·공정도·도면·계약/거래 자료를 IQv2 image/diagram/table로 실제 제시하고, 특정 상표·기관의 비공개 매뉴얼을 복제하지 않는다. 정답에 필요한 기술 정보는 교육과정 또는 제시 자료로 확보한다.
