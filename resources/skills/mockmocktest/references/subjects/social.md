# 사회탐구 전 과목

2027 선택 9과목은 과목당 20문항·30분·50점·2/3점. 2028 통합사회는 25문항·40분·50점·1.5/2/2.5점이다. 최신 체제와 학력평가 범위를 먼저 확인한다.

| 과목 | 문항·자료 설계 | 오류 점검 |
|---|---|---|
| 생활과 윤리 | 윤리적 쟁점, 두 입장 비교, 사례 적용, 대화·논증 구조 | 입장별 필요/충분 조건과 찬반 근거를 구분한다. 사상가의 주장을 가짜 인용으로 만들지 않는다. |
| 윤리와 사상 | 동서양 사상·사회사상의 핵심 개념과 비교 | 비슷한 용어의 학파별 의미를 확인하고 사상가 간 주장을 뒤바꾸지 않는다. |
| 한국지리 | 지형 사진·지형도·기후도·인구/산업 지도 | 위치·축척·방향·단위·기준 연도, 지역별 분모를 확인한다. |
| 세계지리 | 기후 그래프·경관 사진·주제도·이주/자원 자료 | 남북반구·계절·시차·위도·범례를 확인한다. |
| 동아시아사 | 사료·교류 지도·연표·유물 | 동시대 국가명·사건 순서·교류 경로를 대조한다. |
| 세계사 | 문명·종교·정치 변화 사료·지도·통계 | 유럽 중심 한 지역만 과대표집하지 않고 범위와 기출의 지역 분포를 따른다. |
| 경제 | 수요/공급·시장 변화·국민경제·국제거래의 표와 그래프 | 명목/실질·총량/한계·이동/곡선 이동·기회비용·환율 표시 방향을 구분하고 계산한다. |
| 정치와 법 | 헌법·정치제도·법 적용의 가상 사례, 선거 자료 | 적용 법·사건 시점·권리 주체·절차를 명확히 한다. 최신 제도는 공식 자료로 확인하고 발문에 필요한 조건을 준다. |
| 사회·문화 | 연구 설계·자료 수집·계층/불평등·사회 변동 통계 | 표본과 모집단·상관과 인과·비율의 분모·중복 집단·가중치를 확인한다. |
| 통합사회(2028) | 통합사회1·2의 시간적·공간적·사회적·윤리적 관점, 인권·정의·시장·문화·인구·환경 자료 | 여러 관점을 연결하되 개별 선택과목의 심화 법·경제·철학 지식을 전제로 삼지 않는다. |

지도·사진을 말로만 대체하지 않는다. 범주 자료는 `graph`, 통계표는 `table`, 수요공급 좌표 그래프와 지도는 `diagram` 또는 검증한 `image`를 쓴다. 그래프 축 범위·방향·단위, 표의 합계·비율을 별도로 계산한다.

가상 통계는 가상이라고 밝히고 현실 통계처럼 출처를 붙이지 않는다. 실제 수치·법·지명은 출처와 기준 시점을 확인한다. 정답이 자료로 결정되는지, 자료만으로 판단 불가인 선택지가 정답과 충돌하지 않는지 검사한다.
