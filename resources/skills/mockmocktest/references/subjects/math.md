# 수학

2027은 수학Ⅰ·수학Ⅱ 공통 + 확률과 통계/미적분/기하 중 선택, 2028은 대수·미적분Ⅰ·확률과 통계 공통이다. 세부 문항 수·시간·배점은 체제 문서를 따른다. 전국연합은 해당 월 범위를 확인한다.

| 범위 | 새 자료와 변형 | 반드시 검산 |
|---|---|---|
| 수학Ⅰ·대수 | 지수·로그·삼각함수·수열의 관계, 함수 그래프, 귀납적 규칙 | 정의역, 로그 조건, 주기, 수열 시작 인덱스, 경계값 |
| 수학Ⅱ·미적분Ⅰ | 극한·연속·미분·적분의 개념 적용과 그래프 해석 | 연속 조건, 극값과 최댓값 구분, 부호, 적분 구간·넓이 |
| 확률과 통계 | 순열·조합·확률·확률분포·통계 자료 | 표본공간, 중복 계수, 독립/조건부 구분, 확률 합과 모수 |
| 미적분(2027 선택) | 해당 범위의 수열 극한·급수·여러 함수 미적분 | 수렴 조건, 치환·부분적분 조건, 정적분 부호 |
| 기하(2027 선택) | 이차곡선·평면벡터·공간도형과 공간좌표 | 벡터 방향, 좌표·길이·각도 조건, 투영 관계, 도형의 존재 |

수식은 인라인 `$...$` 또는 `math` 블록의 LaTeX로 쓴다. JSON 안 역슬래시는 두 번 이스케이프한다. 좌표평면·곡선·다면체·복합도형은 `diagram` 또는 정확히 검증된 이미지, 통계 그래프는 `graph`, 수치표는 `table`로 제공한다. 그림을 피해서 문항 유형을 바꾸지 않는다.

`graph`의 점 간 간격은 범주 간격이다. 수치 x축의 간격이 중요하거나 함수 곡선을 그릴 때는 수학적으로 계산한 좌표를 `diagram`에 넣는다. 함수 표본 사이 보간으로 잘못된 극값·절편이 생기지 않게 한다. 축·원점·눈금·점 이름을 표시하고 실제 축척과 발문 조건을 대조한다.

단답형은 `type: "단답형"`, `answerText: ["정답"]`, `matchMode: "exact"`로 저장한다. 수능형 정답은 실제 답안 표기 범위를 지키며 필요하면 분자+분모 등 구할 값을 발문에 정의한다. 정답만 맞추지 말고 조건 충족·모든 해·유일성을 다른 풀이 또는 계산 도구로 검사한다. 풀이 시간 내 계산량과 원본 난도 분포를 유지한다.
