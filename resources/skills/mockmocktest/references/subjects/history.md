# 한국사

20문항·30분·50점·2/3점, 절대평가·필수 영역이다. 교육과정의 핵심 역사 소양을 평가하며 지엽적 인명·연도 암기로 난도를 부풀리지 않는다.

기준 회차의 시대 분포(선사·고대, 고려, 조선, 근대, 일제강점기, 현대), 자료 형식, 사고 기능(사실 확인·시기 파악·선후·인과)을 분석한다. 사료·지도·연표·유물/유적 사진·포스터·통계 자료를 새 문항에 실제로 제공한다.

- 사료는 검증된 출처를 사용하고 요약·재구성 여부를 밝힌다. 현대 번역의 이용 조건도 확인한다.
- 유물 사진은 정답에 필요한 형태·문양이 선명해야 한다. 시대 식별을 묻는 사진에 작품명·연도가 정답으로 노출되지 않게 한다.
- 지도는 해당 시기의 국경·지명·방향을 맞춘다. 오늘날의 국경을 옛 지도에 무심코 넣지 않는다.
- 연표는 실제 선후와 기간을 검사하고, 제도·단체·법률은 적용 시대를 대조한다.
- 두 사료를 결합해 묻더라도 핵심 단서를 숨겨 여러 시대가 가능한 문항을 만들지 않는다.

사진은 `image`, 지도·연표는 `diagram` 또는 `table`로 넣는다. 출처는 해설에 기록하고 문제를 풀 때 필요한 조건은 문제 자료 안에 제시한다.
