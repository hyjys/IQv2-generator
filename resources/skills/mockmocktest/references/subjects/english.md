# 영어

45문항·70분·100점, 2·3점, 듣기 17개 포함이라는 수능 구조와 해당 회차 배열을 확인한다. 학력평가는 실제 범위를 따른다.

## 듣기

IQv2 PDF는 오디오를 재생하지 않는다. 실제 듣기 연습을 원하면 별도 음성/낭독이 필요하다고 알린다. 기본 파일에는 듣기 대본을 해당 문항의 `explanation.media` 안 `paragraph`로 넣어 **해설지에서** 교사가 읽을 수 있게 한다. 문제지에 대본을 싣는 읽기 대체 연습을 사용자가 원하면 문항 `boxes`로 옮기고 방식 차이를 밝힌다. 대본을 생략한 채 완성된 듣기 시험이라고 말하지 않는다.

대화 목적·의견·관계·그림 불일치·할 일·수치·이유·언급 여부·표 선택·응답·담화 묶음 등은 기출에서 실제로 확인한 구성을 따른다. 그림·시간표·가격표가 정답 근거인 문항은 이미지·diagram·table을 반드시 넣는다. 대본과 표의 할인·수량·시간을 검산한다.

## 읽기

| 기능 | 검증할 내용 |
|---|---|
| 목적·심경·주장·요지·주제·제목 | 중심 내용과 범위가 일치하고 부분 정보 오답이 정답처럼 되지 않는다. |
| 도표·내용 일치·안내문 | 실제 그래프/표/안내 자료를 제공하고 부정 발문의 정답 개수를 검사한다. |
| 어법·어휘 | 표시 위치와 선택지 번호를 맞추고 교육과정 수준의 유일한 오류를 만든다. |
| 빈칸·함축 의미 | 앞뒤 논리·지시 관계에서 정답 근거를 찾을 수 있어야 한다. |
| 순서·삽입·무관한 문장 | 지시어·연결어·정보의 주어진/새로운 순서가 유일하게 결정된다. |
| 요약·장문 묶음 | 요약이 원문 의미를 보존하고 동일 지문을 쓰는 문항의 답이 서로 누설되지 않는다. |

새 지문은 기출의 단어 수·문단 수·문장 복잡도·주제 범위를 유지한다. 낯선 어휘에는 필요한 경우 원본 방식의 주석을 달고, 번역투·문법 오류가 난도를 대신하지 않게 한다. 발문·선택지의 한국어/영어 사용도 해당 유형에 맞춘다.
