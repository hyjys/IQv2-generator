# 제2외국어 8개 언어·한문

**2027은 30문항·40분·50점·1/2점, 2028은 20문항·30분·50점·2/3점**이다. 모두 5지선다·절대평가이며 9과목 중 하나를 고른다. 2027 과목명은 각 언어Ⅰ·한문Ⅰ, 2028 개정 과목명은 해당 언어·한문이다. 실제 목표 공고를 확인한다.

공통 평가 축은 발음·철자, 어휘, 문법, 의사소통, 문화(한문은 별도 독해)다. 기출에서 그 비중과 문항 기능을 분석하되 미래 번호별 배치를 고정하지 않는다.

| 과목 | 특화 점검 |
|---|---|
| 독일어 | 명사 대문자·움라우트·ß, 성/수/격과 관사, 동사 위치, 호칭과 상황 격식 |
| 프랑스어 | 악센트·축약·성/수 일치, 대명사·동사 활용, 상황에 맞는 인사/요청 |
| 스페인어 | 강세표시·ñ·¿/¡, 성/수 일치·동사 활용, 인칭·격식에 맞는 표현 |
| 중국어 | 간체자·한어병음·성조, 양사·어순·수량/시간 표현, 문맥에 맞는 응답 |
| 일본어 | 가나·한자 표기·장음/촉음, 조사·활용·경어, 상대/상황에 맞는 발화 |
| 러시아어 | 키릴 문자·강세 표기 필요성, 성/수/격·동사 형태, 일상 의사소통 |
| 아랍어 | 오른쪽→왼쪽 본문과 숫자/라틴 문자의 섞임, 문자 연결·필요한 모음 부호, 성/수·문장 구조 |
| 베트남어 | 성조·발음 구별 부호, 어순·분류사, 관계에 맞는 호칭·의사소통 |
| 한문 | 한자의 음·뜻, 성어·허사·문형, 단문/산문의 구조·맥락과 교훈; 교육과정 한자 범위 |

안내판·메뉴·시간표·지도·그림 대화처럼 시각 자료가 있는 유형은 표·diagram·image로 실제 제공한다. 원문자의 글꼴·부호가 인쇄 후에도 구별되는지 확인한다. 아랍어는 문자열을 수동으로 뒤집지 말고 논리 순서 Unicode를 쓴다.

문화 문항은 교육과정에 근거한 상황 판단으로 만들고 고정관념·특정 집단 일반화에 의존하지 않는다. 어휘나 문법 하나를 바꿀 때 문장 전체의 일치·뜻도 재검토한다. 정답을 원어 문맥으로 다시 검토하고 철자 불확실성을 오답의 근거로 삼지 않는다. 과도한 희귀 어휘나 심화 문법으로 난도를 높이지 않는다.

## 일본어·중국어 자료를 JSON으로 작성할 때

한국어 발문 안에 외국어를 섞는 경우 해당 구간을 `span lang`으로 감싼다. 일본어는 `ja`, 간체 중국어는 `zh-Hans`, 번체는 `zh-Hant`를 기본으로 쓰고, 대만·홍콩 등의 지역 자형이 실제 자료에 중요하면 `zh-TW`·`zh-HK` 등 공통 규격의 허용 값을 선택한다. 다음은 **자료 블록 형식 예제**이며 독음을 묻는 문항에 정답 읽기를 미리 제시하지 않는다.

```json
{
  "type": "paragraph",
  "text": "일본어 자료: <ruby lang=\"ja\">図書館<rp>(</rp><rt>としょかん</rt><rp>)</rp></ruby>。중국어 자료: <span lang=\"zh-Hans\">图书馆</span> / <span lang=\"zh-Hant\">圖書館</span>。"
}
```

lang는 글꼴의 지역별 자형을 고르는 정보이고 문자를 번역하거나 간체·번체로 바꾸는 명령이 아니다. `図/图/圖`처럼 다른 코드 포인트는 자료에 맞는 실제 문자로 쓴다. 원문에 있는 IVS·구자체·이체자를 손대지 않고, 확인되지 않은 variation selector를 붙이지 않는다. 독음은 ruby/rt/rp로, 본문 언어는 span/ruby의 lang로 구분한다. 허용하지 않는 style·class·임의 HTML은 사용하지 않는다.

정답 필드에는 태그를 넣지 않는다. 이체자 구별을 묻는 단답형은 exact로 비교하고, 자료·선택지·해설의 같은 글자가 PDF와 퀴즈에서 일관되게 보이는지 확인한다. 특정 IVS 자형이 지원되지 않으면 정확히 검증된 이미지와 명확한 설명을 사용한다. 세부 규칙과 공식 근거는 [IQv2 규격](../IQV2-SCHEMA.md)의 일본어·중국어 절을 따른다.
