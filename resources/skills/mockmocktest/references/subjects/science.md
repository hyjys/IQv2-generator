# 과학탐구 전 과목

2027 선택 8과목은 과목당 20문항·30분·50점·2/3점. 2028 통합과학은 25문항·40분·50점·1.5/2/2.5점이다. 같은 이름의 분야라도 Ⅰ·Ⅱ·통합과학의 교육과정 깊이를 섞지 않는다.

| 과목 | 자료·핵심 과정 | 검산·오류 점검 |
|---|---|---|
| 물리학Ⅰ | 운동·에너지·물질과 전자기·파동 자료, 힘/회로/광학 도식 | 힘 방향·부호·기준계·전하·에너지 보존·그래프 기울기/넓이 |
| 물리학Ⅱ | 해당 심화 범위의 역학·전자기·파동/현대물리 자료 | 벡터 성분·각도·장의 중첩·회로 연결·경계 조건, Ⅰ과 범위 구별 |
| 화학Ⅰ | 입자 모형·주기율·결합·양적 관계·산염기 자료 | 원자/이온 수·전하·원소 보존·몰/농도 단위·반응 계수 |
| 화학Ⅱ | 상태·용액·열·평형·반응 속도·전기화학 자료 | 온도/압력 고정 조건·상수 단위·평형 변화·전극 부호·물질 수지 |
| 생명과학Ⅰ | 세포/개체 자료·항상성·유전·생태, 가계도·실험 | 세대·성별·유전자형·표현형·염색체 수·대조군·생태 수량 |
| 생명과학Ⅱ | 세포 대사·유전자 발현·생명공학·진화 자료 | 가닥 방향·염기/코돈·효소/기질·물질 이동·계통도 분기 근거 |
| 지구과학Ⅰ | 지층·기상/해양·천체 관측 자료, 사진·단면·시계열 | 시간/방위·축·단위·관측자 위치·지층 선후·자료 결측 |
| 지구과학Ⅱ | 지구 구성·지각/대기/해양 운동·우주 관련 자료 | 좌표계·회전 방향·깊이·위도·보존 관계·관측 기하 |
| 통합과학(2028) | 통합과학1·2의 과학 기초·물질과 규칙성·시스템·변화·환경과 에너지·과학과 미래사회 | 관찰→가설→변인 통제→자료→결론의 논리; 선택 심화 개념을 요구하지 않는다. |

`diagram`으로 회로·광학·실험 장치·가계도·입자 모형을, `table`·`graph`로 수치 자료를, `image`로 현미경·경관·천체 사진을 제공한다. 도식을 지원하지 않는다는 이유로 해당 유형을 빼지 않는다. 복잡한 그림은 정확히 그린 래스터 자료를 포함해도 된다.

라벨, 연결선, 극성, 화살표, 단위, 스케일바와 본문을 일치시킨다. 실제 관측/사진과 가상 모형을 구분한다. 흑백에서도 구분할 레이블을 주고 정답을 색만으로 판별하게 하지 않는다. 수치는 법칙을 만족하도록 먼저 계산한 뒤 제시한다. 변인을 한 번에 바꾸어 결론이 모호해지거나 존재할 수 없는 유전자형·반응·천체 배치가 되지 않게 점검한다.
