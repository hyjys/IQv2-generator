# 국어

체제별 과목·문항 수는 [2027](../01-system-2027.md), [2028 이후](../02-system-2028.md)를 따른다. 기준 회차에서 평가 능력, 지문 묶음, 읽기량, 배점, 공통·선택 경계를 직접 추출한다.

| 범위 | 변형 설계 | 자료·검증 |
|---|---|---|
| 독서 | 설명·논증 구조, 두 관점 비교, 조건 적용, 추론을 보존한다. 낯선 개념도 지문 안 정보로 풀 수 있게 한다. | 지문 내 표·그래프는 IQv2 자료로 제공한다. 사실을 확인한 실제 출처를 `source`에 기록하고 없는 책·논문을 만들지 않는다. |
| 문학 | 현대시·고전시가·현대소설·고전소설·극·수필 중 원본 갈래와 작품 간 비교 구조를 보존한다. | 화자/서술자, 시점, 시공간, 표현과 효과의 근거가 실제 실린 구절에 있어야 한다. `author`·`work`를 적는다. |
| 화법과 작문(2027 선택) | 발표·토론·대화·초고·고쳐쓰기의 목적, 청자, 담화 맥락을 새로 만든다. | 자료 화면·도표·초고의 레이블이 문항 지칭과 맞는지 확인한다. |
| 언어와 매체(2027 선택) | 교육과정 안 음운·형태·통사·의미·국어사, 매체의 복합 표현을 묻는다. | 예문을 규칙과 예외에 모두 대입한다. 카드뉴스·화면 자료는 표·도식·이미지로 읽을 수 있게 제공한다. |
| 화법과 언어(2028) | 담화 맥락과 언어 탐구를 해당 성취기준에 맞게 결합한다. | 2027 선택 영역 번호를 그대로 가져오지 않는다. |
| 독서와 작문(2028) | 여러 자료의 신뢰성·관점, 독서 결과의 재구성·글쓰기 과정을 다룬다. | 읽기-쓰기 자료 간 대응과 수정 근거를 확인한다. |

지문은 원본의 문단 수·분량·정보량과 비슷하게 새로 쓴다. 고전도 현대 번역·편집본의 이용 조건은 별도 확인한다. 자유 이용할 수 있는 작품을 사용하거나 같은 갈래의 새 작품을 만들되 실존 작가의 작품으로 표시하지 않는다. AI 창작물은 `author: "AI 창작"` 또는 실제 알려진 모델명과 새 제목을 쓴다.

밑줄·굵게·㉠ 등의 표시를 본문·발문·선택지에서 일치시킨다. `__밑줄__`, `**굵게**`를 사용하고 HTML 태그를 넣지 않는다. 독서 출처는 해설에 표시되므로 정답에 필요한 정보는 지문에도 제시한다.
