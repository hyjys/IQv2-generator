# 공통 출제·변형 원칙

## 실전과 같은 평가

목표는 첨부한 시험과 비슷한 조건에서 개념 적용·추론·자료 해석을 연습하는 것이다. 직전 연습의 기본 난도는 실전보다 약간 높게 잡되 기본·중간·고난도 문항의 분포와 제한 시간 내 풀이량을 보존한다. 교육과정 안에서 조건 결합·추론·매력적 오답을 더하되, 모든 문항을 어려워지게 하거나 사교육 풀이 기술·교육과정 밖 개념·지나친 계산량에 의존하지 않는다. 한국사는 핵심 역사 소양 평가라는 성격을 유지한다.

| 보존할 기준 | 새로 작성할 내용 |
|---|---|
| 기준 회차의 평가 능력·배점·문항 형태 | 상황·소재·수치·선택지 |
| 지문 묶음과 자료를 읽는 과정 | 논리적으로 완결된 새 지문·자료 |
| 지문 길이·정보량·풀이 시간 | 오답 근거와 정답 위치 |
| 해당 학년·월의 교육과정 범위 | 같은 성취기준 안의 적용 사례 |

지문은 요약본처럼 줄이지 않는다. 문단 수·문장 수·어휘 수준·자료 밀도를 원본과 비교한다. 긴 글에만 의존해 난도를 높이지 않는다. 번호 배열은 기준 회차의 관찰 결과이지 모든 미래 시험의 확정 사항이 아니다.

## 자료를 실제로 제공하기

- 수식은 LaTeX, 표는 `table`, 범주별 수치 그래프는 `graph`, 좌표·기하·회로·실험 배치는 `diagram`을 쓴다. 여러 표·그림을 읽는 문제가 원본에 있다면 그 읽기 과정을 보존한다.
- 사진이 필요한 지리·역사·생물·직업 자료는 사용 권한이 있는 실제 사진이나 정확성이 검증된 생성 이미지를 포함한다. 사실 식별에 쓰는 사진은 정답을 결정하는 특징이 정확히 보여야 한다.
- 사진은 검증한 이미지 바이트를 data URL로 넣는다. 임의 URL·가짜 base64·외부 사이트 링크·이미지 자리표시자를 넣지 않는다. 사용할 사진이 없으면 검증 가능한 도식으로 재설계하거나 필요한 자료만 요청한다.
- 실험 그래프·회로·지도·기하 도형은 단위, 축, 범례, 방향, 연결 관계를 확인한다. 도형의 겉보기 길이만으로 답이 정해지게 하지 않는다. 흑백 인쇄에서도 구분되도록 레이블을 쓴다.
- 실측 통계는 실제 출처·기준 연도를 기록하고, 가상 수치는 가상 자료라고 밝힌다. 원문 그림의 저작권·이용 조건은 글과 별도로 확인한다.

## 근거와 정답

출처를 확인한 개념만 사용하며 존재하지 않는 논문·서적·URL을 만들지 않는다. 기출의 긴 지문·선택지를 복제하지 않는다. 공개 이용 가능한 고전도 현대 번역·편집본의 권리를 별도로 확인한다. EBS 자료가 있으면 개념·주제·자료를 간접적으로 활용하고 확인하지 않은 연계율을 달성했다고 주장하지 않는다.

계산형은 다른 풀이 또는 계산 도구로 검산한다. 선택형은 정답 외 네 선택지가 왜 틀린지, 복수 정답 가능성이 없는지 검사한다. 자료 밖 사실을 알아야만 풀리는 문항이면 필요한 조건을 추가한다. 듣기 원고를 문제지에 넣는 경우 실제 듣기 평가와 다른 연습 방식임을 알린다.

## 출력 전 점검

- 목표 학년도·과목·선택과목·학년과 월별 범위가 일치한다.
- 문항 번호가 1부터 연속이고 지문 참조·자료 레이블이 모두 존재한다.
- 총 문항 수, 배점 합, 시간, 지문 분량이 기준 설계와 맞는다. 2028 탐구의 1.5·2·2.5점도 보존한다.
- 5지선다 `choices`는 정확히 5개, 정답 `answer`는 1~5다. 단답은 `answerText` 배열이다.
- 모든 문항을 다시 풀었고 `explanation.correct`가 실제 지문·자료에 근거한다.
- 수식·사진·표·그래프·도형·선택지 자료가 빠짐없이 있으며 표기와 정답이 일치한다.
- JSON은 IQv2 2.0 `kind: "exam"`이며 검증 오류·자리표시자·생략 문항이 없다.
