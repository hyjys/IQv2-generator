# 모의모의고사 출제

실제 시험 직전 연습용 시험지를 만든다. 최종 파일은 Akademiya 공통 **IQv2 2.0 `kind: "exam"`인 `exam.json`**이다. 레이아웃과 PDF는 HAFStudy가 만든다.

## 시작 조건과 체제 선택

최근 1~3개년 같은 과목·회차의 기출 문제지 PDF 또는 해당 체제의 평가원 공식 예시문항을 먼저 읽는다. 자료가 없으면 문항을 만들기 전에 이를 요청한다. 사용자에게 이미 받은 조건을 다시 묻지 않는다.

핵심 조건은 **목표 시험 학년도**, 시험 종류·월, 학년, 영역·과목, 범위다. 국어·수학의 옛 선택 체제에서는 선택과목도 확인한다. 학년도는 시행 연도와 다르다(예: 2027학년도 수능은 2026년 시행). **학년만 보고 고3=2027, 고1·2=2028로 고정하지 않는다.** 재수생·조기 준비·지난 체제 연습도 목표 시험을 따른다.

- 2027학년도: [2015 개정 체제](references/01-system-2027.md).
- 2028학년도 이후: [2022 개정 통합 체제](references/02-system-2028.md)를 시작점으로 해당 학년도 최신 공식 공고를 확인한다.
- 전국연합 학력평가: 해당 학년·월의 **실제 출제 범위·문항 수**를 우선한다. 고1·고2 시험에 수능 전 범위를 그대로 적용하지 않는다.
- 공식 근거·갱신 방법: [출처 목록](references/03-official-sources.md). 인터넷 확인을 할 수 없으면 제공 자료와 확인된 기준일을 밝히고 미래 변경을 단정하지 않는다.

## 출제 흐름

1. [공통 원칙](references/00-principles.md)과 해당 체제·과목 문서를 읽는다.
2. 첨부물에서 `번호 / 평가 능력·단원 / 유형 / 배점 / 지문 범위 / 자료 형식 / 예상 풀이 시간`을 추출한다. 여러 회차라면 사용자가 지정한 회차, 없으면 가장 최근의 **같은 체제**를 기준으로 삼는다.
3. 교육과정 범위, 지문 분량, 배점, 난도 분포, 듣기·단답형 비중을 유지하며 새 지문·자료·문항을 만든다. 번호별 유형은 **분석한 기준 회차의 설계**로 사용하고 미래 수능의 고정 규칙이라고 말하지 않는다. 체제가 달라지면 공식 예시문항을 근거로 설계를 새로 세운다.
4. 도표·사진·그래프·도형이 핵심인 문항에는 실제 읽을 수 있는 IQv2 자료를 넣는다. 그림을 피하거나 `[그래프 삽입]` 같은 자리표시자로 대체하지 않는다. 수치는 계산하고 사진·출처·이용 조건을 확인한다.
5. 각 문항을 자료만 보고 다시 풀어 정답 유일성·오답 근거·풀이 시간을 점검한다. 모든 문항에 해설을 넣는다.
6. [공통 출력 규격](references/OUTPUT-SCHEMA.md)과 [예제](references/example.json)에 맞춰 JSON을 검증하고 제공한다. 도형이 있으면 공통 출력 규격의 **도형의 글자와 인쇄 여백** 기준으로 제목·축·범례를 확인한다. 측정·인쇄 검증은 [Noto CJK 글꼴](references/PRINT-FONTS.md)을 사용하고, 시스템에 없으면 공식 글꼴을 임시로 받아 호출한다. 인쇄 검증이 가능하면 문제지와 해설지를 각각 확인한다. `meta.exam.kind`는 `mockmock`이다.

최종 JSON 제공 전에 표지 필적 확인 문구가 아직 정해지지 않았다면 한 번 묻고 빈칸 선택도 안내한다. 이미 문구 또는 빈칸 의사를 받았다면 다시 묻지 않는다. 받은 문구는 `meta.exam.signaturePhrase`에 넣고, 빈칸을 선택하면 생략한다. 문구를 기다리는 동안 문항 작성·검증을 계속한다.
