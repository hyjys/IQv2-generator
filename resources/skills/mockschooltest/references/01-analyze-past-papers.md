# 기출 유형 분석 — 문항을 만들기 전에 반드시 먼저

첨부된 그 학교 기출을 분석하지 않고 문항을 만들면 안 된다.
분석 결과를 **사용자에게 먼저 보여주고** 넘어간다.

## 분석 항목

### 1) 문항 구성표

각 문항에 대해 아래를 정리한다.

| 번호 | 형태 | 배점 | 다룬 개념 | 자료 출처 | 비고 |
|---|---|---|---|---|---|
| 1 | 5지선다 | 3 | ○○ 개념 | 교과서 본문 p.42 | |
| 2 | 단답형 | 4 | △△ | 학습지 3번 변형 | |

### 2) 통계

- 총 문항 수 / 총점 / 시험 시간
- 형태별 비율: 선택형 몇 문항, 단답형·서술형 몇 문항
- 배점 분포: 2점 몇 개, 3점 몇 개, 4점 몇 개
- 서술형이 있다면 **몇 번에 배치되는가**(보통 뒤쪽에 몰린다)

### 3) 출제 관행 — 이 학교만의 특징

아래를 찾아 정리한다.

- **자료 출처 비중**: 교과서 본문 / 학습지·프린트 / 외부 지문(EBS·모의고사) 중 어디서 주로 가져오는가
- **발문 어투**: "가장 적절한 것은?" / "옳지 않은 것은?" / "서술하시오" 등 반복되는 형식
- **함정 스타일**: 부정 발문(적절하지 **않은**) 빈도, `<보기>` 사용 여부
- **난이도 배치**: 앞이 쉽고 뒤가 어려운가, 고르게 섞여 있는가
- **반복 출제 개념**: 여러 개년에 걸쳐 계속 나오는 개념 — 변형본에 반드시 포함한다

### 4) 개년 간 차이

2개년 이상 받았다면 무엇이 달라졌는지 정리하고, **가장 최근 회차**를 기준으로 삼는다.
출제자가 바뀐 흔적(어투·형태의 급변)이 보이면 사용자에게 알린다.

분석이 끝나면 아래 형식으로 요약해 보여주고 확인을 받은 뒤 출제로 넘어간다.

> **○○고 ○학년 ○○ 기말고사 기출 분석**
> - 총 25문항 / 100점 / 50분

> - 자료의 70%가 학습지에서, 30%가 교과서 본문에서 나옴
> - 부정 발문("않은 것은?")이 8문항으로 비중이 큼
