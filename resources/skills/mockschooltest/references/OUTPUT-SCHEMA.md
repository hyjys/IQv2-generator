# 시험지 출력 — Akademiya IQv2 2.0

최종 산출물은 **IQv2 `exam.json` 하나**다. HTML·CSS·PDF를 만들지 않는다. [IQv2 공통 규격](IQV2-SCHEMA.md)을 먼저 읽고 아래 인쇄용 규칙을 함께 적용한다. HAFStudy의 **AI 변형 시험지** 메뉴에 올리면 문제지·해설지 PDF가 만들어진다. 같은 IQv2 구조는 ImsiQuiz·HAFStudy 퀴즈의 JSON 가져오기에서도 쓴다.

## 시험 메타데이터

```json
{
  "schemaVersion": "2.0",
  "kind": "exam",
  "meta": {
    "title": "2028학년도 대비 통합과학 모의모의고사",
    "subject": "통합과학",
    "language": "ko",
    "mode": "exam",
    "timeLimitSec": 2400,
    "revealPolicy": "atEnd",
    "shuffleQuestions": false,
    "shuffleChoices": false,
    "exam": {
      "kind": "mockmock",
      "grade": 3,
      "periodLabel": "제 4 교시",
      "system": "2028",
      "confidential": false
    }
  },
  "questions": []
}
```

위는 메타데이터 예시다. 실제 파일의 `questions`는 완성된 문항으로 채운다.

- `meta.exam.kind`: 모의모의고사는 `mockmock`, 모의내신은 `mockschool`.
- `meta.exam.system`: 적용한 **목표 학년도** 문자열. 현재 학년으로 추정하지 않는다.
- `meta.exam.grade`: 학년 1~3. `periodLabel`은 교시 문구. 학교 시험은 `organization`에 학교명.
- `meta.exam.confidential`: 첨부 자료에 공유 제한이 있으면 `true`.
- `meta.exam.signaturePhrase`: 최종 출력 전 아직 문구/빈칸 의사를 받지 않았다면 한 번 확인한다. 이미 받은 응답은 다시 묻지 않는다. 사용자가 준 문구만 넣고 빈칸 선택 시 생략한다.
- 시험 시간은 분이 아닌 **`meta.timeLimitSec`의 초**다. 문항 수·총점은 실제 `questions`에서 계산하므로 옛 `totalQuestions`, `totalPoints`, `durationMinutes`를 만들지 않는다.
- 옛 `schemaVersion: "1.0"`, 최상위 `kind: "mockmock"/"mockschool"`, 문자열 `answer`는 신규 생성에 쓰지 않는다. 기존 파일 가져오기 호환성만 남아 있다.

## 지문·문항

지문은 `passages: [{id,range:[시작번호,끝번호],instruction,body,media?,boxes?,source?,author?,work?}]`로 저장한다. 해당 문항의 `passageId`가 그 id를 참조한다. `range` 머리글을 `body`에 중복으로 쓰지 않는다. 문단은 빈 줄 두 개가 아니라 JSON 문자열의 `\n\n`, 줄바꿈은 `\n`이다.

문항은 `number`, `points`, `type`, `prompt`, 정답, `explanation.correct`가 필요하다. 문항 번호는 1부터 연속이다. 5지선다는 문자열 5개의 `choices`와 숫자 1~5의 `answer`; 단답·서술형은 `answerText` 배열이다. 학교 서술형을 단답형으로 위장하지 않는다. 배점은 양의 0.5 단위 숫자이며 2028 탐구의 1.5·2·2.5점을 그대로 쓴다.

자료 배열 `media`는 문항·지문·보기 상자·해설에 넣을 수 있다. 선택지별 자료는 `choiceMedia`에 `choices`와 같은 길이의 배열을 넣고, 자료 없는 선택지는 빈 배열 `[]`로 둔다. 해설 자료는 문제의 정답을 누설하지 않도록 `explanation.media`에 둔다.

비문학 자료의 실제 출처는 `passages[].source`에 기록한다(해설지 표시). 문학은 `author`·`work`에 실제 정보를 넣고 AI 창작물은 창작 사실을 밝힌다. 정답에 필요한 정보는 출처 표시에만 두지 않는다.

## 수식·서식·시각 자료

- 텍스트의 `**굵게**`, `__밑줄__`, `*기울임*`, `~~취소선~~`을 쓸 수 있다. 한글 옆에도 쓰되 표식 쌍을 닫는다.
- 인라인 수식은 `$...$`, 독립 수식은 `$$...$$` 또는 `{ "type": "math", "latex": "...", "display": true }`이다. LaTeX 역슬래시는 JSON에서 `\\`로 저장한다. 수식을 HTML로 바꾸지 않는다.
- `table`은 표, `graph`는 막대/선 범주 그래프, `shape`는 단순 도형, `diagram`은 좌표·레이블·여러 도형을 조합한 자료다. 정확한 필드와 한도는 공통 규격을 따른다.
- 일본어·중국어 본문은 `<span lang="ja|zh-Hans|zh-Hant">…</span>` 형태의 언어 표기와 `ruby/rt/rp` 독음 태그를 쓸 수 있다. 실제 lang 값 하나를 골라 넣고, 지역 값·정확한 허용 목록·JSON 이스케이프는 공통 규격을 따른다. 원문 코드 포인트·IVS를 보존하며 lang만 바꾸어 간체/번체 문자 자체가 변환된다고 가정하지 않는다.
- 이 인라인 태그 외의 원시 SVG/HTML, JavaScript, Mermaid 코드를 미디어 대신 넣지 않는다. 표는 table 미디어를 쓴다. 사진이나 복잡한 자료는 실제 이미지 바이트로 제공한다.
- 필요한 자료를 생략하거나 `[사진 삽입]`·`...` 같은 자리표시자를 넣지 않는다. 사진에 대한 대체 텍스트도 정답을 직접 노출하지 않는다.

### 도형의 글자와 인쇄 여백

`diagram`의 `width`·`height`는 자료의 좌표 영역이다. `text.y`는 글자의 위쪽이 아니라 **기준선**이므로, 좌표가 영역 안에 있어도 글자의 윗부분이 밖으로 나갈 수 있다. 로컬에서 맞는 그림도 서버의 Noto CJK 글꼴에서는 글자 높이·폭이 달라질 수 있다.

글자 크기·여백을 실제로 측정하거나 인쇄 검증을 할 때는 [Noto CJK 설치 확인·미설치 시 호출](PRINT-FONTS.md)을 따른다. 설치되어 있지 않으면 공식 글꼴을 임시로 받아 로드하고, 대체 글꼴 결과만으로 서버에서 인쇄된다고 판단하지 않는다.

- 자료 전체 제목은 가능하면 `caption`에 두고, 그림 안에 필요한 국가명·축 이름·수치만 `text`로 배치한다. 글자·선 두께·화살촉까지 포함해 외곽에 8px 정도 여백을 둔다.
- 상단 제목의 기준선은 권장값 `y >= fontSize × 1.5 + 8`로 잡는다. 예를 들어 높이 240의 그림에 18px 제목을 넣을 때 `y: 17.52` 대신 `y: 36`처럼 충분히 내리고 본문 도형과 간격을 둔다. 하단 레이블도 기준선 아래의 글자 부분과 여백이 남도록 배치한다.
- 좌우 레이블은 `anchor: "start"|"middle"|"end"`에 따라 글자가 펼쳐지는 방향과 **전체 문자열의 폭**을 고려한다. 중앙 정렬은 양쪽, 끝 정렬은 왼쪽으로 공간이 필요하다. 여백이 부족하면 좌표·본문 배치를 조정하거나 캔버스를 늘린다. 필요한 제목·범례·수치를 삭제해 맞추지 않는다.
- 인구 피라미드처럼 같은 문항에 여러 그림이 있으면 각 그림의 제목·축·범례 여백을 따로 확인한다. 서버의 작은 글꼴 넘침 보정에 기대어 가장자리에 붙이지 않는다. 큰 좌표 초과·지나치게 긴 레이블은 계속 인쇄 오류가 된다.

## 사진의 임시 사용

PDF용 사진은 `image.src`에 **PNG/JPEG/WebP의 완전한 base64 data URL**을 넣는다. 파일에서 인코딩하고 해독 가능한지 확인한다. 외부 URL, 로컬 파일 경로, 임의로 만든 `iq://` 주소를 넣지 않는다. 퀴즈 업로드에서 발급된 `iq://u/...`는 공통 IQv2에서 쓰이지만, 다른 서버로 독립적인 PDF 파일을 보내려면 실제 이미지 데이터가 필요하다.

이미지는 1개 최대 2MiB, 합계 최대 8MiB(해독 후 바이트). 인쇄에 필요한 해상도만 남기고 크기를 줄인다. 서버는 PDF를 굽는 동안만 이미지를 쓰고 렌더링 컨텍스트를 정리한다. 사진 보관함이나 재사용 링크를 기대하지 않는다. 사용자가 받은 JSON과 완성 PDF에는 자료가 남으므로 재생성용 원본은 사용자가 보관한다.

## 최종 확인

JSON 파싱과 IQv2 검증, 정답 유일성, 배점 합, 지문 참조, 누락 미디어를 확인한다. 도형은 좌표뿐 아니라 글자·선·화살촉의 전체 범위와 여백도 점검한다. 형식 검증 통과나 해설지 생성만으로 문제지 생성까지 성공했다고 판단하지 않는다. HAFStudy 또는 같은 Chromium 인쇄 경로를 사용할 수 있으면 **문제지와 해설지를 각각 생성**해 제목·자료의 잘림과 내용 누락을 확인한다. 그 환경이 없으면 JSON·좌표 검증과 PDF 생성 미검증을 구분해 안내하며, 시험지 스킬의 최종 산출물은 계속 `exam.json` 하나다.

`example.json`은 자료 형식 데모이며 완전한 수능 한 회분이 아니다. 실제 요청에서 예제의 문항 수·범위·정답을 복사하지 않는다.
