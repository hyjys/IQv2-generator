# 모의내신 공통 원칙

## 1. 내신은 모의고사와 무엇이 다른가

| | 모의고사(수능형) | 내신(학교 시험) |
|---|---|---|
| 번호별 유형 | 고정 | **고정하지 않음** |
| 범위 | 교육과정 전체 | **그 학기 진도 범위만** |
| 출제 주체 | 평가원·교육청(전국 공통) | **그 학교 선생님** |
| 자료 출처 | 새 지문 | **수업에서 다룬 자료·학습지** |
| 문항 형태 | 5지선다·수학 단답형 | 학교마다 다름(서술형·단답형 비중) |

따라서 내신은 **"그 학교 선생님이 낼 법한 문제"** 를 만드는 일이다.
전국 공통 유형이 아니라 **첨부된 기출에서 읽어낸 그 학교의 관행**을 따른다.

## 2. 변형의 정의

| 따른다 (그 학교 관행) | 새로 만든다 |
|---|---|
| 문항 형태 비율(선택형/단답형 비중) | 문항 내용 |
| 배점 분포와 총점 | 지문·자료 |
| 자료 활용 방식(교과서 본문/학습지/외부 지문) | 선택지 |
| 발문 어투와 지시문 형식 | 정답 위치 |
| 난이도 체감 | |

⚠️ **지문 길이는 원본(학습지·교과서 발췌·기출 지문)과 비슷하게 유지한다.** 짧게 요약하지 마라.

## 3. 범위 준수 — 가장 중요

- **시험 범위를 벗어나는 문항은 만들지 않는다.** 범위 밖 개념이 필요하면 사용자에게 먼저 묻는다.
- 범위 자료가 불명확하면 추측하지 말고 되묻는다.
- 학교 학습지·프린트를 받았다면 **거기서 다룬 자료를 최우선**으로 변형 대상에 넣는다.
  내신은 수업 자료에서 그대로 나오는 경우가 많다.

## 4. 난이도

**그 학교 기출의 난이도보다 약간 높게** 잡되 풀이 시간과 범위를 지킨다. 계산량·애매한 함정 대신 개념 적용과 추론을 더한다.
내신은 만점 방어가 목표이므로, 실수를 유발하는 함정보다 **범위 전체를 고르게 덮는 것**이 더 중요하다.

- 기출에서 자주 나온 개념은 변형본에도 반드시 포함한다.
- 범위 안에서 한 번도 안 나온 개념도 한두 문항 넣어 빈틈을 메운다.

## 5. 금지 사항

- 첨부물(기출 + 범위 자료) 없이 문항을 만드는 것
- 시험 범위를 벗어난 출제
- 기출 문항의 그대로 복제
- 정답이 둘이거나 없는 문항
- `exam.json` 외의 시험지 파일 생성

## 6. 자기 점검 (출력 전 반드시)

- [ ] 모든 문항이 시험 범위 안에 있는가
- [ ] 기출 분석 결과를 사용자에게 보여 주었는가
- [ ] **지문 길이가 원본과 비슷한가** — 짧게 줄어들지 않았는가
- [ ] 실제 문항의 배점 합이 학교 시험 총점과 맞는가
- [ ] 그 학교의 문항 형태 비율(선택형/단답형)을 따랐는가
- [ ] `meta.exam.organization`에 학교 이름을 넣었는가
- [ ] 저작권 문구가 있었다면 `meta.exam.confidential`이 `true`인가
- [ ] 모든 문항에 유형에 맞는 `answer` 또는 `answerText`와 `explanation`이 있는가
- [ ] JSON이 문법적으로 유효한가
