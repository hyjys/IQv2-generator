# 수학 (내신)

학교 교과서·학습지의 성취기준, 문항 형태, 서술형 비율, 풀이 시간과 배점을 따른다. 공식만 바꾼 반복이나 불필요한 계산량으로 난도를 늘리지 않는다.

- 풀이를 끝까지 검산하고 조건을 만족하는 해가 실제로 존재하며 유일한지 확인한다.
- 수식은 LaTeX로 쓴다. 인라인은 `$...$`, 독립식은 `math` 블록을 쓰며 JSON 역슬래시는 두 번 이스케이프한다.
- 그래프·기하 도형·좌표·통계표가 필요한 유형은 IQv2 graph/diagram/table/image로 실제 제공한다. 축·눈금·정의역·점 이름·비례를 검사한다.
- 단답형은 `answerText` 배열을 쓴다. 서술형은 `type: "서술형"`과 모범답안을 쓰고 `explanation.correct`에 단계별 풀이·부분 점수 기준을 넣는다.
- 학교에서 허용하는 해법·기호·반올림·답안 형태를 따르고, 아직 배우지 않은 단원으로 풀이를 대체하지 않는다.
