# 영어 (내신)

## 내신 영어의 특징

- **범위 안의 지문(교과서 본문, 학습지·부교재 지문)에서 그대로 나온다.** 이게 수능형과의 결정적 차이다.
- 본문 암기 수준의 정확한 이해를 요구한다: 빈칸, 어법, 어휘, 순서, 요약, 내용 일치.
- 서술형(영작·단어 배열·빈칸 채우기)이 있는 학교가 많다.

## 변형 시 주의

- **범위 지문을 벗어나지 마라.** 새 외부 지문을 가져오면 내신 연습이 되지 않는다.
- 같은 지문에 대해 묻는 지점을 바꾼다: 같은 문단의 다른 빈칸, 다른 어법 포인트, 다른 요약문.
- 어법 문항은 **그 지문에 실제로 있는 문법 요소**로만 낸다(관계사, 분사, 수일치, 태, 가정법 등).
- 단답형은 `answerText`에 허용 답안 배열을 쓰고, 영작 등 서술형은 `type: "서술형"`과 모범답안·채점 기준을 쓴다. 문법 평가에서 대소문자·구두점이 중요하면 `matchMode: "exact"`로 둔다.
- 지문을 `passages[].body`에 넣을 때 원문 인용은 시험에 필요한 최소 범위로 한다.

## 자주 나오는 형태

- 본문 빈칸 추론 / 어법상 틀린 것 / 문맥상 낱말의 쓰임
- 주어진 단어 배열해 문장 완성(서술형)
- 본문 내용과 일치하지 않는 것
- 지칭 추론, 요약문 완성
