# 모의내신 스킬 (mockschooltest) v2026.10.1

학교 중간·기말고사 대비 "모의내신" 시험지를 만드는 스킬입니다.
**Claude와 ChatGPT 모두에서 쓸 수 있습니다.**

## Claude에서 쓰기

1. 이 폴더를 통째로 ZIP으로 압축해 Claude의 **스킬(Skill)** 로 업로드합니다.
   (Claude Code를 쓴다면 `~/.claude/skills/mockschooltest/` 에 폴더째 넣어도 됩니다.)
2. 새 대화에서 학교 기출 PDF와 시험 범위 자료를 첨부하고 "모의내신 만들어줘"라고 요청합니다.

## ChatGPT(또는 다른 AI)에서 쓰기

1. ZIP을 풀어 `SKILL.md` 와 `references/` 안의 파일들을 대화에 첨부합니다.
   - 최소한 `SKILL.md`, `references/00-principles.md`, `01-analyze-past-papers.md`,
     `02-scope-materials.md`, `03-copyright.md`, 해당 과목 문서, `references/OUTPUT-SCHEMA.md`, `references/IQV2-SCHEMA.md`를 함께 넣으세요.
2. 같은 대화에 **학교 기출 문제지 PDF**와 **시험 범위 자료**를 첨부합니다.
3. "첨부한 SKILL.md 절차대로 모의내신 exam.json을 만들어줘"라고 요청합니다.

## 무엇이 나오나요

이 스킬의 산출물은 **IQv2 2.0 `exam.json` 파일 하나**입니다. 시험지 디자인(표지·2단 본문·해설지)은
AI가 만들지 않습니다.

`exam.json`을 **HAFStudy → AI 변형 시험지** 메뉴에 올리면
문제지 PDF와 해설지 PDF가 만들어집니다. https://hafs.akademiya.kr

> 로그인한 이용자라면 사용할 수 있습니다.
> 생성된 PDF에는 내려받은 사람의 이름과 이메일이 워터마크로 들어갑니다.

## 준비물

- **(필수)** 해당 학교 최근 1~3개년 기출 문제지 PDF
- **(필수)** 이번 시험의 시험 범위 자료
- (권장) 정답·해설 자료, 학교 학습지·프린트
- **(필수)** 학교 이름, 학년, 과목, 시험 종류

첨부물이 없으면 스킬은 문항을 만들지 않고 무엇이 필요한지만 안내합니다. 정상 동작입니다.

## 저작권 주의

학교 기출 문제지는 수능·모의고사와 달리 **엄격하게 저작권이 관리**됩니다.
첨부한 자료에 저작권·유출 금지 문구가 있으면 생성된 PDF 좌하단에
"외부 유출 금지 · 개인 사용 전용" 문구가 빨간 글씨로 자동 삽입됩니다.
만들어진 시험지는 **본인 학습용으로만** 사용하세요.
